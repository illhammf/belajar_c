# 💻 Menjalankan Program

## 1. Pastikan GCC Terinstall

Cek:

```bash
gcc --version
```

Jika berhasil, akan muncul informasi versi GCC.

---

## 2. Compile Program

Masuk ke folder program:

```bash
cd pertemuan-13
```

Kemudian:

```bash
gcc sistem_mahasiswa.c -o sistem_mahasiswa
```

---

## 3. Jalankan

### Windows

```bash
sistem_mahasiswa.exe
```

### Linux / macOS

```bash
./sistem_mahasiswa
```

# 📁 Data File

Final Project menggunakan:

```text
data_mahasiswa.txt
```

Format penyimpanan:

```text
NIM|Nama|Jurusan|IPK
```

Contoh:

```text
23123456|Ilham Firmansyah|Informatika|3.85
23123457|Budi|Sistem Informasi|3.70
23123458|Andi|Teknik Komputer|3.90
```

File ini digunakan agar data tetap tersedia meskipun program ditutup.
